# Бесплатные события Москвы — Telegram-дайджест

Бот ежедневно собирает бесплатные события Москвы и ближайшего Подмосковья и отправляет подборку в Telegram.

## Что подключено

- KudaGo: бесплатные события, даты, адреса, координаты и ссылка на источник.
- Timepad: публичные события, бесплатные билеты/регистрация, адреса, координаты и ссылка на источник.
- Дедупликация похожих событий.
- Геофильтр: по умолчанию 55 км от центра Москвы — практическое приближение «Москва + примерно 30 км за МКАД».
- Дайджест до 18 событий на ближайшие 7 дней.
- Автоотправка каждый день в 09:00 МСК через GitHub Actions.

## Важно про Telegram-токен

Не добавляйте токен в файлы репозитория. Храните его только в GitHub Actions Secrets.
Если токен был опубликован в чате/репозитории, перевыпустите его через BotFather.

## Быстрый запуск

1. Создайте приватный GitHub-репозиторий и загрузите туда эти файлы.
2. В Telegram откройте своего бота и отправьте `/start`.
3. Чтобы узнать `chat_id`, локально выполните:

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN='ВАШ_ТОКЕН'
python get_chat_id.py
```

4. В GitHub: `Settings → Secrets and variables → Actions → New repository secret`.
5. Создайте два секрета:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
6. Откройте `Actions → Daily Moscow Free Events → Run workflow` для теста.
7. После теста workflow будет запускаться автоматически каждый день в 09:00 МСК.

## Локальный предпросмотр без отправки

```bash
python main.py --preview
```

## Настройки

Через переменные окружения:

- `MAX_EVENTS` — сколько событий присылать, по умолчанию 18.
- `SEARCH_DAYS` — горизонт поиска, по умолчанию 7 дней.
- `SEARCH_RADIUS_KM` — радиус от центра Москвы, по умолчанию 55 км.
- `MOSCOW_CENTER_LAT`, `MOSCOW_CENTER_LON` — центральная точка геофильтра.

## Следующее расширение

Для VK, Instagram и Telegram-каналов лучше использовать их официальные API/разрешённые интеграции. Прямой HTML-парсинг соцсетей намеренно не включён в ядро: он нестабилен и часто требует авторизации.
